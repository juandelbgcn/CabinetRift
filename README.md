# CabinetRift

CabinetRift: A distributed, cloud-native platform for real-time home inventory management with auto-scaling and data-driven services.

CabinetRift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CabinetRift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CabinetRift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
